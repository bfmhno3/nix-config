# Changelog

## [1.0.0] - 2026-08-20

First stable release.

- NixOS configurations: `thinkpad-t14s`, `test-vm`, `wsl2`.
- Packages: `fcitx5-themes-candlelight`, `google-sans-flex`, `illogical-impulse-microtex`, `illogical-impulse-quickshell`, `grub2-theme`.
- Project templates: `stm32`, `rust`, `qt6`, `embedded-linux`.
- Root flake outputs support `x86_64-linux` only.
- Standalone templates declare both `x86_64-linux` and `aarch64-linux`.
